# Guía de pruebas reales - SGCE 1.0.140

## Prueba mínima después de instalar

1. Entrar al sistema.
2. Guardar configuración.
3. Crear un ciclo y periodos.
4. Crear maestro, grupo, materia y alumno.
5. Crear asignación.
6. Capturar asistencia.
7. Capturar calificación.
8. Generar reporte.
9. Crear aviso.
10. Crear usuario maestro.
11. Generar respaldo.
12. Revisar consulta pública.
13. Revisar bitácora.

## Prueba visual

Verifica que las transiciones se noten en login, dashboard, avisos, periodos, maestros, grupos, materias, alumnos, asignaciones, expedientes, reportes, planeaciones, asistencias, calificaciones, usuarios, respaldos, migración, configuración y bitácora.
