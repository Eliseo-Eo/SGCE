# Manual de Usuario SGCE 2026 FINAL

## 1. Acceso
Entrar a index.php con usuario y contraseña asignados. El sistema redirige según el rol: administrador, docente u otros roles autorizados.

## 2. Panel administrador
El dashboard muestra accesos rápidos, alumnos activos, maestros, grupos, asistencias del día, faltas y promedio general. El botón de cerrar sesión solicita confirmación.

## 3. Maestros
Permite registrar docentes manualmente o importar CSV/Excel. Para importar, el archivo debe contener Nombre, Usuario y Contraseña. El sistema pide confirmación antes de procesar.

## 4. Grupos
Permite registrar grado, grupo y turno. El grado usa números, el grupo usa letras y el turno debe ser MATUTINO o VESPERTINO. También puede importarse CSV/Excel.

## 5. Alumnos
Permite inscribir alumnos manualmente o importar listas por grupo. Antes de importar verifica que el grupo seleccionado sea correcto.

## 6. Asignaciones
Relaciona maestro, grupo y materia. Esta asignación habilita asistencia, calificaciones y planeaciones para el docente.

## 7. Docente
El portal del docente muestra materias asignadas. Si no tiene materias, se muestra un aviso cerrado correctamente con su tachita alineada. Desde cada materia puede pasar asistencia, calificar y exportar reportes.

## 8. Asistencia
El docente selecciona la materia y registra A, F, R o J. El sistema evita duplicar pase de lista para la misma materia, alumno y día.

## 9. Calificaciones
Las calificaciones se capturan por periodo. El sistema valida valores y permite guardar cambios por grupo/asignación.

## 10. Reportes y respaldos
El sistema genera reportes PDF/Excel y respaldos de solo datos. Para importar un respaldo, se muestra una confirmación antes de ejecutar.

## 11. Buenas prácticas
Cerrar sesión al terminar, revisar archivos antes de importar, respaldar antes de cambios grandes y usar siempre el módulo de respaldo oficial.
