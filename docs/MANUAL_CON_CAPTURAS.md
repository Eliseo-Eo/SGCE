# Manual con capturas - SGCE 1.0.140

Este documento es una guía limpia para agregar capturas reales después de instalar SGCE en el entorno definitivo.

## Capturas recomendadas

1. Verificación del instalador.
2. Login institucional.
3. Dashboard administrativo.
4. Módulos de Maestros, Grupos, Materias, Alumnos y Asignaciones.
5. Portal docente.
6. Planeaciones docentes.
7. Captura de asistencias.
8. Captura de calificaciones.
9. Reportes PDF/Excel.
10. Respaldos y restauración.
11. Migración de ciclo escolar.

## Criterio de captura

Cada imagen debe mostrar la pantalla completa, el navegador actualizado y datos de prueba no sensibles. No incluyas contraseñas ni información personal real.
