# Manual guiado con capturas — SGCE 1.0.122

> Este manual incluye los puntos donde deben colocarse capturas reales del sistema instalado. La versión de código no incluye imágenes tomadas de tu servidor porque cada instalación puede tener tema, datos y URL distintos.

## 1. Instalación

**Captura sugerida:** Pantalla inicial del instalador.

1. Sube el contenido de `Produccion/` al servidor.
2. Abre `Instalar.php`.
3. Captura datos de escuela, ciclo, oferta educativa, turnos y escala de calificaciones.
4. Crea el usuario administrador.

## 2. Importar información base

**Captura sugerida:** Módulos Maestros, Grupos, Materias y Alumnos.

Orden recomendado:

1. Maestros.
2. Grupos.
3. Materias por grupo.
4. Alumnos.
5. Asignaciones.

## 3. Migración escolar

**Captura sugerida:** Panel de diagnóstico de migración.

1. Crear ciclo nuevo.
2. Activarlo.
3. Verificar periodos.
4. Simular migración.
5. Ejecutar migración.
6. Revisar grupos, materias y alumnos promovidos.

## 4. Panel docente

**Captura sugerida:** Panel del maestro con Asistencia, Calificaciones y Planeaciones.

## 5. Reportes y consulta pública

**Captura sugerida:** Boleta o consulta de alumno.
