# Roadmap SGCE

## Pendiente recomendado

- Crear pruebas automatizadas con base de datos temporal.
- Agregar pruebas automatizadas reales con base de datos temporal para importaciones completas.
- Convertir exportaciones Excel grandes a streaming real si el volumen crece mucho.
- Evaluar paginación por cursor en bitácora si supera cientos de miles de registros.
- Agregar autenticación de dos pasos opcional para administradores.
